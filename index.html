A complete management system for a Zambian family farm — livestock with weight-gain tracking, crops and fields, finances in Kwacha, tasks, rainfall, vaccinations, a breeding outlook and a knowledge base. Everything keeps working when the network doesn't.

Version 1.0 · Package built 18 September 2026

🚀 How to run the app

  1. 1
    Install Bun (or use Node.js 18+)
    # macOS / Linux / WSL
curl -fsSL https://bun.sh/install | bash
  2. 2
    Install dependencies (from this folder)
    bun install
  3. 3
    Start the dev server
    bun run dev   # then open http://localhost:3000

ℹ️ This index.html is a launcher page. Farm Command itself is a Next.js application — the steps above start it, and then you can install it to your home screen from the running app (Settings → About → Install app).

Designed for the network you don't have

Every record is written first to your device (IndexedDB via Dexie) and queued for sync — so logging a weight, a sale or a vaccination works in the field with zero signal. When connectivity returns, the sync engine pushes your changes with idempotency and last-write-wins conflict handling. Weather and the AI assistant are the only online features, and they say so honestly.
